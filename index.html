01 · База

Теорія без зайвого

Функція — це правило, яке кожному допустимому значенню x ставить у відповідність єдине значення y.

y = f(x)
Запам’ятай головне

Аргумент x — незалежна змінна, а y — залежна. Значення функції змінюється разом зі зміною аргументу.

x → y
◎

Область визначення D(f)

Усі значення x, для яких формула має зміст. Наприклад, у √(x − 2) маємо x ≥ 2.

↕

Область значень E(f)

Усі значення y, яких набуває функція. Для y = x² це y ≥ 0.

⌁

Графік функції

Множина точок (x; f(x)) на координатній площині. Кожній вертикалі — не більше однієї точки.

Ключові властивості

01
Нулі функції

Точки, де графік перетинає вісь Ox: f(x) = 0.

02
Знак функції

Проміжки, де графік вище осі Ox — f(x) > 0, а нижче — f(x) < 0.

03
Монотонність

Функція зростає, якщо зі збільшенням x збільшується y; спадає — якщо зменшується.

04
Парність

Парна: f(−x)=f(x) — симетрія відносно Oy. Непарна: f(−x)=−f(x).

Основні формули
Лінійнаy = kx + b
Квадратичнаy = ax² + bx + c
Обернена пропорційністьy = k/x, k ≠ 0
Модульy = |x|
Порада: починай аналіз із області визначення та ключових точок.
∑
Теорема про нулі квадратного тричлена

Для ax² + bx + c = 0 дискримінант D = b² − 4ac визначає кількість коренів: D > 0 — два, D = 0 — один, D < 0 — дійсних коренів немає.

02 · Розбір

Приклади крок за кроком

Не просто дивись на відповідь — відстежуй логіку розв’язання.

Приклад 01область визначення

f(x) = √(3x − 6)

01 Підкореневий вираз не від’ємний: 3x − 6 ≥ 0.

02 Переносимо: 3x ≥ 6 → x ≥ 2.

Відповідь: D(f) = [2; +∞)
Приклад 02вершина параболи

f(x) = x² − 4x + 3

01 Виділяємо квадрат: f(x) = (x − 2)² − 1.

02 Вершина має координати V(2; −1); вісь симетрії: x = 2.

Відповідь: мінімум f(2) = −1
Приклад 03нуль функції

f(x) = 2x − 8

01 Прирівнюємо до нуля: 2x − 8 = 0.

02 Отримуємо x = 4. Графік перетинає Ox у точці (4; 0).

Відповідь: нуль функції — x₀ = 4
Приклад 04парність

f(x) = x⁴ − 3x²

01 Замінимо x на −x: f(−x) = (−x)⁴ − 3(−x)².

02 Спрощуємо: f(−x) = x⁴ − 3x² = f(x).

Відповідь: функція парна
Приклад 05практична задача

Рух велосипедиста

01 Відстань задає формула s(t) = 12t, де 12 — швидкість (км/год).

02 За 2,5 години: s(2,5) = 12 · 2,5 = 30.

Відповідь: 30 км

03 · Практика

Перевір себе

Розв’яжи самостійно, а потім відкрий підказку для перевірки.

01Область визначенняf(x) = 1/(x − 5)+
Знаменник не може дорівнювати нулю: x ≠ 5. Отже, D(f) = (−∞; 5) ∪ (5; +∞).
02Нулі функціїf(x) = x² − 9+
Розклад: (x − 3)(x + 3) = 0. Нулі: x₁ = −3, x₂ = 3.
03Дослідження знакаf(x) = −2x + 6+
Нуль у x = 3. Функція додатна на (−∞; 3) і від’ємна на (3; +∞).
04Вершина параболиf(x) = x² + 6x + 5+
Виділяємо квадрат: (x + 3)² − 4. Вершина: V(−3; −4).
05Парністьf(x) = x³ + 2x+
f(−x) = −x³ − 2x = −f(x), тому функція непарна.
06Значення функціїf(x) = 3x − 1, x = −2+
f(−2) = 3 · (−2) − 1 = −7.
